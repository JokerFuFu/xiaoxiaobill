# 老账单项目 API 接口文档

## 一、API 概览

| 类别 | 接口数量 | 说明 |
|-----|---------|-----|
| 数据分析 API | 17 | 核心数据分析接口 |
| 文件管理 API | 4 | 上传、删除、列出文件 |
| 会话管理 API | 3 | 演示模式、会话状态 |
| 元数据 API | 3 | 获取可用日期、年份、分类 |
| 认证与多用户 API | 9 | 登录/登出/当前用户/改密 + 管理员用户管理 |
| AI 助手 API | 15 | AI 状态/模型配置/智能分析/对话/账单识别 |
| 邮箱账单 API | 5 | 邮箱配置/测试/拉取/导入(含加密附件解密) |
| 资产负债 API | 6 | 账户、快照、净资产趋势 |
| 对账与资金性质 API | 3 | 对账报告 + 自定义资金性质口径规则 |

## 三、数据分析 API

GET /api/analysis?year=2024&min_amount=10&max_amount=1000

| 参数 | 类型 | 必填 | 说明 |
|-----|------|-----|-----|

| min_amount | float | 否 | 最小金额 |
| max_amount | float | 否 | 最大金额 |

    "success": true,

## 认证与多用户 API

对应蓝图 `backend/api/auth.py`。除 `bootstrap` 为公开接口外，用户接口需登录，管理员接口需管理员权限（`@login_required` + `@admin_required` 双重校验）。

### 用户接口

| 路由 | 方法 | 用途 | 关键入参 | 返回要点 |
|-----|------|-----|---------|---------|
| `/api/auth/bootstrap` | GET | 首次安装引导（公开）：全新部署且管理员仍用初始口令时，告知默认账号方便首次登录；改密后返回 `fresh=false` 不再暴露信息 | 无 | `success`，`fresh` 及首次安装相关字段 |
| `/api/auth/login` | POST | 登录（成功后清除演示态，`remember=True`） | `{username, password}` | 成功 `{success, user}`；失败 401 `用户名或密码错误` |
| `/api/auth/logout` | POST | 登出（清除演示态） | 无 | `{success: true}` |
| `/api/auth/me` | GET | 当前登录/演示用户信息 | 无 | `{success, authenticated, is_demo, user?}` |
| `/api/auth/password` | POST | 修改自己的密码（需校验原密码） | `{old_password, new_password}` | 成功 `{success: true}`；原密码错误 400 |

### 管理员接口

| 路由 | 方法 | 用途 | 关键入参 | 返回要点 |
|-----|------|-----|---------|---------|
| `/api/admin/users` | GET | 列出全部用户 | 无 | `{success, users}` |
| `/api/admin/users` | POST | 创建用户 | `{username, password, display_name?, role?}`（role 默认 `user`） | `{success, user}` |
| `/api/admin/users/<uid>` | DELETE | 删除用户（不能删除当前登录账号） | 路径参数 `uid` | `{success: true}` |
| `/api/admin/users/<uid>/password` | POST | 重置某用户密码 | `{password}` | `{success: true}` |

## AI 助手 API

对应蓝图 `backend/api/ai.py`。AI 配置采用「多档案 + 功能分配」模型：每个功能（chat/analysis/recognize）可分配不同模型档案，未分配时回落默认档案与环境变量默认。接口绝不下发明文 API Key。

### 状态与模型配置

| 路由 | 方法 | 用途 | 关键入参 | 返回要点 |
|-----|------|-----|---------|---------|
| `/api/ai/status` | GET | AI 是否可用 + 当前模型名 | 无 | `{success, enabled, model, source}` |
| `/api/ai/config` | GET | 全部档案（Key 掩码）、功能分配、默认档案、自定义供应商模板 | 无 | `{success, config}` |
| `/api/ai/config` | PUT | 保存功能分配/默认档案/自定义供应商模板/自动分析开关（不改档案与 Key） | `{assignments?, default_profile?, custom_providers?, auto_analyze?}` | `{success, config}` |
| `/api/ai/config/test` | POST | 测试连接：可直接给 `base_url/api_key/model`，或给档案 `id` 回落已存值 | `{id?/profile_id?, base_url?, api_key?, model?}` | `{success, ok, message}` |
| `/api/ai/profiles` | POST | 新增/更新模型配置档案（带 `id`=更新，`api_key` 缺省=保留、`''`=清除） | `{id?, name, base_url, model, api_key?}` | `{success, profile_id, config}` |
| `/api/ai/profiles/<pid>` | DELETE | 删除某档案 | 路径参数 `pid` | `{success, config}` |

### 智能分析

| 路由 | 方法 | 用途 | 关键入参 | 返回要点 |
|-----|------|-----|---------|---------|
| `/api/ai/analyze` | GET | 取某维度已缓存的分析报告（不触发生成） | query `scope`、`year?`、`month?` | `{success, report, auto, enabled}` |
| `/api/ai/analyze` | POST | 生成（或取缓存）某维度的 AI 分析报告 | `{scope, year?, month?, force?}` | `{success, report}`；未配置 503；无数据/未知维度 400 |

### 对话

| 路由 | 方法 | 用途 | 关键入参 | 返回要点 |
|-----|------|-----|---------|---------|
| `/api/ai/chat` | POST | 对话式检索/分析交易（工具调用形式访问账单） | `{question, chat_id?, history?}` | `{success, chat_id, answer, tool_calls?, ...}` |
| `/api/ai/chats` | GET | 列出对话历史 | 无 | `{success, chats}` |
| `/api/ai/chats/<cid>` | GET | 取某会话详情 | 路径参数 `cid` | `{success, chat}`；不存在 404 |
| `/api/ai/chats/<cid>` | PUT | 重命名会话 | `{title}` | `{success}` |
| `/api/ai/chats/<cid>` | DELETE | 删除会话 | 路径参数 `cid` | `{success}` |

### 账单识别与导出

| 路由 | 方法 | 用途 | 关键入参 | 返回要点 |
|-----|------|-----|---------|---------|
| `/api/ai/recognize` | POST | 智能识别账单：上传 `file`（csv/txt/xlsx/pdf）或传 `{text}` → 返回交易预览 | multipart `file` + `hint?` 或 JSON `{text, hint?}` | `{success, rows, count}` |
| `/api/ai/recognize/import` | POST | 把识别结果导入到某成员（写成支付宝样式 CSV） | `{rows, member_id?, name?}` | `{success, filename, count}` |
| `/api/ai/exports/<path:filename>` | GET | 下载 AI 导出的文件（仅当前用户 `_exports` 目录，限 xlsx/csv） | 路径参数 `filename` | 文件下载；非法文件名 400；不存在 404 |

## 邮箱账单 API

对应蓝图 `backend/api/mail.py`。用于从邮箱 IMAP 自动拉取支付宝/微信账单邮件并导入，支持加密 zip/PDF 附件解密。所有接口需登录（无 uid 时 401）。授权码只回传布尔，不下发明文。

| 路由 | 方法 | 用途 | 关键入参 | 返回要点 |
|-----|------|-----|---------|---------|
| `/api/mail/config` | GET | 读取邮箱配置（授权码仅回布尔） + 服务商预设 | 无 | `{success, config}` |
| `/api/mail/config` | POST | 保存邮箱配置（`auth_code=''` 清除；`auto_import` 开启自动导入需配置完整） | `{host?, port?, address?, auth_code?, auto_import?}` | `{success, config}` |
| `/api/mail/test` | POST | 测试邮箱连接 | 无 | `{success, ok, message}` |
| `/api/mail/fetch` | POST | 拉取近 N 天的账单邮件列表 | `{days?}`（默认 90） | `{success, mails}` |
| `/api/mail/import` | POST | 导入指定邮件的某个附件（可传解压密码、归属成员） | `{uid, index, zip_password?, member_id?}` | `{success, ...}`；标识/序号不合法 400 |

## 资产负债 API

对应蓝图 `backend/api/networth.py`，为三表模型中的「资产负债表」。所有接口需登录（无 uid 时 401，fail-closed 不落入共享匿名空间）。多数写接口返回时会连带回传最新总览（`accounts/snapshots/trend/explain` 等）。

| 路由 | 方法 | 用途 | 关键入参 | 返回要点 |
|-----|------|-----|---------|---------|
| `/api/networth` | GET | 总览：账户、快照、净资产趋势、解释表、账户/负债类型 | 无 | `{success, accounts, account_types, liability_types, snapshots, trend, explain}` |
| `/api/networth/accounts` | POST | 新增账户 | `{name, type}` | `{success, account, ...总览}` |
| `/api/networth/accounts/<aid>` | PUT | 改名/改类型 | `{name?, type?}` | `{success, ...总览}` |
| `/api/networth/accounts/<aid>` | DELETE | 删除账户（连带各快照中该账户余额） | 路径参数 `aid` | `{success, ...总览}` |
| `/api/networth/snapshots` | POST | 记/改一笔快照 | `{date, balances:{aid:val}, note?}` | `{success, ...总览}` |
| `/api/networth/snapshots/<date>` | DELETE | 删除某天快照 | 路径参数 `date` | `{success, ...总览}` |

| `/api/reconcile` | GET | 全量对账报告（瀑布/性质明细/平台喂养/信用卡/疑似双算） | query `year?`（缺省取最新年份） | `{success, empty, year, years, ...report}`；无数据 `empty=true` |
| `/api/nature/rules` | GET | 用户自定义口径规则 + 可选性质清单与可用字段 | 无 | `{success, rules, natures, fields}` |
| `/api/nature/rules` | POST | 整体替换规则（保存后缓存失效） | `{rules}` | `{success, rules}`；非法 400 |

## 七、关键业务流程

### 7.1 文件上传流程

```
用户上传文件
    │
    ├─→ 检查文件类型 (CSV/XLSX)
    │
    ├─→ 获取/创建会话目录 (/tmp/flask_uploads/{user_id}/)
    │
    ├─→ 生成安全文件名 (secure_filename)
    │
    ├─→ 检测文件来源 (支付宝/微信)
    │
    ├─→ 保存文件
    │
    ├─→ 更新会话时间戳
    │
    └─→ 清除数据缓存
```

---

### 7.2 数据加载流程 (`load_alipay_data()`)

```
load_alipay_data()
    │
    ├─→ [演示模式]
    │    └─→ 加载 sample_data.csv
    │
    └─→ [正常模式]
         ├─→ 遍历会话目录下所有文件
         │
         ├─→ [CSV 文件]
         │    ├─→ 检测来源 (支付宝/微信)
         │    ├─→ 支付宝: GBK 编码, 查找表头行
         │    └─→ 微信: UTF-8-sig 编码, 列名映射
         │
         ├─→ [XLSX 文件]
         │    └─→ header=16, 列名映射
         │
         ├─→ 统一数据处理
         │    ├─→ 添加 '月份', '日期' 列
         │    ├─→ 标记退款 (是否退款)
         │    └─→ 添加 '来源' 标识
         │
         └─→ 合并所有数据, 按时间排序
```

---

### 7.3 会话管理流程

```
用户首次访问
    │
    ├─→ get_session_dir()
    │    ├─→ 生成 user_id (token_hex(16))
    │    └─→ 创建会话目录
    │
    └─→ 数据缓存 (永久有效，除非手动清除)
         └─→ @user_cache 装饰器
```

> **注**: 本地部署模式下，会话不会自动过期，数据持久保存直到用户手动清除。

## 十、错误处理

所有 API 返回格式:

**成功**:
```json
{
    "success": true,
    "data": { ... }
}
```

**失败**:
```json
{
    "success": false,
    "error": "错误信息"
}
```

常见错误:
- `没有文件被上传` - 未选择文件
- `不支持的文件类型` - 非 CSV/XLSX
- `未找到任何支付宝(.csv)或微信(.xlsx)账单文件` - 无有效数据
- `数据缺少必需列` - 数据格式错误

## 十一、文件解析规则

### 支付宝 CSV
- **编码**: GBK (尝试失败则 UTF-8)
- **表头行**: 自动查找包含 "交易时间" 的行
- **状态行**: 查找包含 "交易状态" 的行
- **退款标识**: "退款成功", "交易关闭"

### 微信 CSV
- **编码**: UTF-8-sig
- **表头行**: 自动查找包含 "交易时间" 和 "交易类型" 的行
- **列名映射**:
  - 交易类型 → 交易分类
  - 商品 → 商品说明
  - 金额(元) → 金额
  - 当前状态 → 交易状态
  - 支付方式 → 收/付款方式

### 微信 XLSX
- **表头行**: 第 17 行 (固定)
- **列名映射**: 同微信 CSV
